# Игры разума

«Игры разума» — набор из пяти консольных математических игр, разработанных в рамках учебного проекта Hexlet.

В каждой игре необходимо правильно ответить на три вопроса подряд. При неправильном ответе игра завершается.

## Список игр

- **brain-even** — определение чётности числа
- **brain-calc** — вычисление арифметических выражений
- **brain-gcd** — нахождение наибольшего общего делителя
- **brain-progression** — поиск пропущенного числа в прогрессии
- **brain-prime** — определение простого числа

## Требования

- Python
- uv

## Установка

```bash
git clone https://github.com/PopDevil13/python-project-49.git
cd python-project-49
uv tool install .
```

## Запуск

После установки игры доступны через терминал:

```bash
brain-even
brain-calc
brain-gcd
brain-progression
brain-prime
```
